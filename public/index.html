讓一群 AI 小幫手
替你把日常工作做完

像傳訊息一樣交代工作：查後台、整理訂單、寫試算表、擬好回覆等你按核准。機器人在你自己的電腦上，用你已經有的 Claude、ChatGPT、Gemini 等帳號工作，不用另外付 API 費用。

下載 Windows 版（免費）
Windows 10／11 · 安裝檔約 120 MB · 免費

三步驟開始

  1. 下載安裝 OCTA按上面的下載按鈕，打開安裝檔，再登入或註冊 OCTA 帳號。Windows 若跳出「已保護您的電腦」，按「其他資訊 → 仍要執行」。
  2. 連上一個 AI打開 OCTA 後會出現設定指引。選你已經有帳號的 AI（例如 Claude 或 ChatGPT），按「一鍵安裝並登入」，再按「測試」。沒有付費帳號可以先用 Gemini 的免費額度。
  3. 建立機器人、交代工作從範本開始（門市、民宿、研究…），或自己寫任務。可以設定每天幾點自動做，做完會通知你。

能做什麼

多個機器人分工每個機器人一個任務，拉進群組依序接力，或用 @ 指定誰做。
操作你登入的網站每個機器人有自己的瀏覽器，登入一次就記住，互不干擾。
重要的事先問你發訊息、付款這類動作會先等你按「核准」。
每天自動執行設定時間就會自己做，卡住或需要你時通知電腦、Telegram 或 LINE。
一台主機，到處指揮一台電腦裝 OCTA 當主機，手機、平板、其他電腦打開網頁版登入同一個帳號，就能即時指揮、收到通知。
檔案留在你的電腦附件、截圖、機器人做出的報表都存在主機電腦的資料夾（也可以選 Google 雲端硬碟），每個機器人分開放、可以互相調用。

常見問題

要錢嗎？

OCTA 免費、開源。AI 的部分用你自己的訂閱或免費額度。

桌面版和網頁版差在哪？

兩者用同一個帳號、資料同步。機器人要在電腦上工作，所以至少要有一台電腦裝桌面版並保持開著；之後用手機或其他電腦打開網頁版就能指揮、看結果。

電腦要一直開著嗎？

要。機器人在你的電腦上工作，電腦關機或休眠時會暫停，開機後繼續。

有 Mac 版嗎？

目前先提供 Windows 版；Mac 使用者可以先用網頁版。
